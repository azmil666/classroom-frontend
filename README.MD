A modern, production-grade **admin dashboard** for managing academic institutions — featuring role-based access, real-time analytics, and a highly responsive UI.

Built with a scalable frontend architecture focused on **performance**, **accessibility**, and **developer experience**.

## 🛠️ Getting Started

### ✅ Prerequisites

* Node.js (18+ recommended)
* npm or pnpm

---

### 📦 Installation

```bash
git clone https://github.com/azmil666/classroom-frontend.git
cd classroom-frontend
npm install
```

---

### 🔐 Environment Configuration

Create a `.env` file in the project root:

```env
VITE_BACKEND_BASE_URL=http://localhost:8000/api
VITE_CLOUDINARY_CLOUD_NAME=
VITE_CLOUDINARY_UPLOAD_PRESET=
VITE_CLOUDINARY_UPLOAD_URL=
```

> Replace the values with your Cloudinary credentials.

---

### ▶️ Run Locally

```bash
npm run dev
```

Open in browser:

```
http://localhost:5173
```
